# medr-registry-app

Static Telegram Mini App shell for the perforated-ulcer registry.

This repository contains only the front-end page (HTML/JS/CSS). It stores no patient data, no bot token, and no API keys. The page is opened inside Telegram and loads rows from the existing n8n data webhook, sending Telegram `initData` for authorization.

Intended GitHub Pages URL: https://dimachekmarev.github.io/medr-registry-app/
